本地大模型推理脉络

生成一个 token，要把激活的权重从内存里读一遍，而计算量很小。所以把前沿模型搬出数据中心，难点在内存：放不放得下（容量），读不读得快（带宽）。下面五条技术线和整个商业故事，都在围绕这两个约束。

出发点

解码是在读内存

内存墙（Wulf & McKee, 1995）和 Roofline 模型（Williams & Patterson, 2009）说的是同一件事：算力增长远快于内存带宽。LLM 解码落在带宽受限的那一侧。

每秒 token 上限 ≈ 内存带宽 ÷ 每个 token 要读的字节数
需要的内存 ≈ 总参数 × 每参数比特 ÷ 8（再加 KV cache）
–
权重要占的内存（GB）
–

–
理论上限（token/s）

理论上限，实际一般只有 50–70%；不含 KV cache，长上下文时还要更多内存。示例参数：DeepSeek-V3 总 671B、激活 37B；gpt-oss-120b 约 117B、激活约 5.1B；Qwen3-30B-A3B 约 30.5B、激活约 3.3B。

MoE 改变了账本

MoE 每个 token 只读几十 B 参数，带宽压力小了；但所有专家都得放在内存里，要几百 GB。问题从"带宽不够"转成了"容量不够"。谁能便宜地提供几百 GB、带宽过得去的内存，谁就能在家跑前沿模型。

线 ①

压缩权重：少读字节

时间工作改进了什么
2016Deep Compression（Han，ICLR 最佳论文）、EIE（ISCA）剪枝 + 量化 + 编码，CNN 时代的开山之作
2022LLM.int8()（Dettmers，NeurIPS）发现大模型激活里有离群值，单独用高精度处理，8-bit 不掉点
2023GPTQ（ICLR）训练后一次性量化到 4-bit，用二阶信息逐列补偿误差
2023SmoothQuant（ICML）把激活的离群值转移到权重上，权重和激活都 8-bit
2023–24AWQ（MLSys 2024 最佳论文）关键按激活重要性保护约 1% 的关键权重；成为本地 4-bit 部署的标配
2023QLoRA（NeurIPS）4-bit NF4 底座上微调，消费级显卡能微调大模型
2023–24QuIP / QuIP#、AQLM（ICML 2024）随机旋转消除离群值 + 向量码本，推到 2-bit
2024–25BitNet b1.58 → b1.58 2B4T三值权重 {-1, 0, 1}，从训练开始就低比特，乘法变加法
2025MXFP4 / NVFP4；gpt-oss 以 MXFP4 发布4-bit 浮点进了硬件和官方模型
2026MoE 专家级压缩（如 RFID-MoE，ICML 2026）按专家重要性分配不同压缩率

走向：事后量化 → 量化感知训练、原生低比特训练 → 硬件原生支持 4-bit 浮点

线 ②

KV cache 与注意力：长上下文的内存大头

时间工作改进了什么
2019MQA（Shazeer）所有注意力头共享一份 K/V，KV cache 缩小几十倍
2022FlashAttention（Dao，NeurIPS）关键IO 感知：分块在片上 SRAM 里算，不把注意力矩阵写回显存
2022Orca（OSDI）连续批处理
2023vLLM / PagedAttention（SOSP）关键像操作系统分页一样管理 KV cache，几乎没有碎片
2023GQA（EMNLP）MQA 和多头之间的折中，Llama 2/3 采用
2023–24H2O（NeurIPS 2023）、StreamingLLM（ICLR 2024）只留重要的 token；"注意力汇点"让流式无限长生成成为可能
2024KIVI（ICML）、KVQuant（NeurIPS）KV cache 量化到 2–4 bit
2024MLA（DeepSeek-V2）把 K/V 压成低秩潜向量，KV 大幅缩小
2024–25混合注意力：Jamba、MiniMax-01、Qwen3-Next、Kimi Linear大部分层换成线性注意力或状态空间，KV 几乎不随长度增长

走向：先省带宽（FlashAttention）→ 再省容量（分页、量化、低秩）→ 从模型结构上去掉 KV cache

线 ③

并行解码：读一次权重，多出几个 token

时间工作改进了什么
2022–23投机解码（Leviathan 等 ICML 2023；DeepMind 2023）关键小模型先猜几个 token，大模型一次并行验证；结果和原模型完全一致
2024Medusa（ICML）、EAGLE（ICML）/ EAGLE-2不要独立小模型，在大模型上加预测头；在特征层预测
2024–25MTP（DeepSeek-V3）、EAGLE-3训练时就让模型预测后面几个 token
2025扩散语言模型：LLaDA、Mercury、Gemini Diffusion并行去噪出整段，不再逐个生成

为什么对本地特别重要：本地是单用户、小批量，算力大量闲置。投机解码把闲置的算力换成速度

线 ④

分层存放、按需搬运：容量不够怎么办

时间工作改进了什么
2023FlexGen（ICML）权重和 KV 分到 GPU / CPU / 磁盘，用调度换吞吐
2023Deja Vu（ICML）上下文稀疏性：每个输入只用到一小部分神经元，可预测并跳过
2023-12LLM in a flash（Apple，ACL 2024）关键权重放闪存，只把需要的部分读进 DRAM；窗口化复用、按行列打包读取
2023-12PowerInfer（SOSP 2024）、PowerInfer-2（2024）热神经元放 GPU、冷神经元放 CPU；后来搬到手机
2023–24MoE 专家卸载（如 Mixtral 卸载）只把要用的专家搬进显存
2025KTransformers（清华，SOSP 2025）关键注意力、KV、共享专家放 GPU，路由专家放 CPU 内存；单张 16GB 消费级卡加大内存跑 671B DeepSeek，提速 1.66–19.7 倍
2026DALI、FlashMoE、MoE-CORE、FineMoE（EuroSys '26）专家缓存与预取策略（如证明 LRU/LFU 不适合专家路由）、SSD 直读专家、手机 NPU + 闪存

走向：通用卸载 → 利用稀疏性 → 针对 MoE 的专家放置、缓存和预取（2026 年最热）。反面证据：用 SSD 卸载 MoE 权重，每 token 能耗可达 HBM 的约 12 倍

线 ⑤

模型结构变得对本地友好

时间变化意义
2023-12Mixtral 8x7B开源 MoE 走进大众
2024-12 / 2025-01DeepSeek-V3 / R1关键671B 总参数、激活 37B；MLA + MTP + FP8 训练。开源模型第一次接近前沿
2025Qwen3、Kimi K2（1T）、gpt-oss（MXFP4）前沿开源模型几乎全是 MoE；gpt-oss-120b 单张 80GB 卡可跑
2025–26Qwen3-Next、Kimi Linear；DeepSeek-V4、Qwen3.5激活参数越来越少，KV 越来越小

结论：MoE 让瓶颈从带宽转到容量，这是 Alpaca 这类公司成立的时间背景

为什么是这个时间点

2025 年起前沿开源模型几乎都是 MoE：激活少、总量大，瓶颈转到容量。现成的消费级机器在 128–512GB 这一档又贵又不够。
